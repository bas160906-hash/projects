# Wordloop

Карточки английских слов для телефона. Статическое приложение без сборки и сервера.

## Использование

- Нажмите название набора вверху, отметьте один или несколько наборов и нажмите «Начать». Новая тренировка включает все слова выбранных наборов.
- В том же окне можно отредактировать название набора или удалить его кнопкой «×» с подтверждением.
- Выберите направление EN → RU или RU → EN и порядок: «По порядку» или «Случайно». Переключение порядка меняет очередь оставшихся карточек, сохраняя пройденные. Каждый новый круг в случайном режиме перемешивается заново.
- Нажмите на карточку, чтобы открыть перевод.
- Свайп влево или «Don’t know» возвращает слово в очередь.
- Свайп вправо или «Know» убирает слово из текущего круга.
- После всех слов нажмите «Ещё раз». Кнопка со стрелкой сбрасывает текущий круг.
- Кнопка «+» открывает импорт файла или вставку таблицы.

Наборы и прогресс сохраняются в браузере устройства. Свайпы работают также перетаскиванием мышью; доступны стрелки клавиатуры. При системной настройке уменьшения движения длинные анимации заменяются коротким затуханием.

## Ввод перевода

Кнопка с клавиатурой вверху включает и выключает режим ввода. Настройка сохраняется в браузере. В обычном режиме остаются прежние свайпы и нажатие для открытия ответа.

Введите перевод и нажмите «Проверить» или Enter. Верный ответ автоматически засчитывается как «Know». При ошибке карточка показывает перевод и кнопку «Дальше»: после нажатия слово возвращается в очередь. Пустой ввод не считается ошибкой. Режим работает в обоих направлениях и с объединёнными наборами.

Ответ сравнивается с переводом из файла. Допустимые варианты можно перечислить через запятую или точку с запятой: `разыскивать; присматривать за`. Регистр, повторяющиеся пробелы, разница между «е» и «ё» и конечная пунктуация не учитываются. Синонимы, которых нет в файле, автоматически не распознаются.

## Формат набора

Сохраните таблицу в файл `.md`:

```markdown
| English | Русский перевод |
|---|---|
| serendipity | счастливая случайность |
| resilient | стойкий |
```

## GitHub Pages и телефон

Разместите `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`, папку `icons` и `.nojekyll` в корне репозитория. В настройках Pages выберите публикацию из корня основной ветки.

Откройте опубликованный HTTPS-адрес на телефоне и добавьте приложение на главный экран через меню браузера. В поддерживающих установку браузерах приложение открывается отдельным окном. После первого успешного открытия файлы приложения сохраняются для работы без сети.

Все пути относительные: приложение поддерживает адрес вида `https://username.github.io/repository/`.

Для просмотра без публикации можно открыть `index.html`. Установка и сервис-воркер требуют HTTPS или localhost. Прогресс из локального файла не переносится автоматически в опубликованный сайт.
